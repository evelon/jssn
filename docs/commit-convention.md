## Commit Convention

type(scope): subject

### Type

- feat: 새 기능 추가 (신규 feature의 spec 문서 작성 포함)
- fix: 버그 수정
- docs: 기존 내용에 대한 문서/설명 보완
- refactor, test, chore ...

### Scope

- spec: 스펙 문서
- conv: 컨버터 프로그램
- (생략 가능) root 디렉토리 파일 수정 시 scope 없이 작성

### 예시

feat(spec): OO 기능 명세 작성
feat(conv): JSON→XML 변환 로직 추가
docs(spec): 기존 스펙 설명 보완
