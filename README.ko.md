# JSSN

JSSN(JSON Schema Simplified Notation)은 JSON으로 표현된 데이터의 스키마를 나타내기 위해 개발 중인 표기법입니다. JSON Schema를 대체하기보다는 보완하는 것을 목적으로 합니다.

JSSN은 두 가지 설계 원칙을 따릅니다. JSON Schema와의 호환성, 그리고 가독성입니다.

0.1.0 버전 기준으로 JSSN은 JSON Schema의 기본 타입 규칙만을 다루며, 이를 구현한 JSON Schema → JSSN 변환기가 제공됩니다. 앞으로는 호환 가능한 문법을 점차 추가해 나갈 예정입니다. 자세한 내용은 `spec/CHANGELOG.md`와 `converter/CHANGELOG.md`를 참고하세요.
