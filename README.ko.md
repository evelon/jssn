# JSSN

JSSN(JSON Schema Simplified Notation)은 JSON으로 표현된 데이터의 스키마를 나타내기 위해 개발 중인 표기법입니다. JSON Schema를 대체하기보다는 보완하는 것을 목적으로 합니다.

JSSN은 두 가지 설계 원칙을 따릅니다. JSON Schema와의 호환성, 그리고 가독성입니다.

JSSN의 명세는 기능별로 하나씩 문서로 정리되어 있습니다 — 현재 다루는 범위와 로드맵은 [spec/README.md](spec/README.md)를 참고하세요. 다루는 문법을 구현한 JSON Schema → JSSN 변환기도 제공됩니다 — 사용법은 [converter/README.md](converter/README.md)(영문)를 참고하세요. 자세한 내용은 `spec/CHANGELOG.md`와 `converter/CHANGELOG.md`를 참고하세요.
